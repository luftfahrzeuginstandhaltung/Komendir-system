## 🇧🇷 Sobre o Projeto

O **LexKomendirAircraft** é uma proposta brasileira de engenharia, pesquisa aplicada e formação técnica em manutenção aeronáutica e operação estratégica. O ecossistema integra documentação, análise, visualização holográfica e organização de dados com foco em inovação e soberania tecnológica.

**Do Brasil para o Mundo.**

## 🛠️ Como Executar

### Requisitos
- Python 3.8+
- `matplotlib`
- `Flask`

### Instalação
```bash
pip install -r requirements.txt
pip install matplotlib
```

### Execução local do sistema web
```bash
python app.py
```

Abra:
```text
http://localhost:5000
```

### Execução do sistema terminal
```bash
python komendir_completo.py
```

## 🚀 Funcionalidades

- Camadas de operação: `DADOS`, `ANÁLISE`, `PREVISÃO`, `QUÂNTICO`
- Geração de dashboard visual
- Exportação de landing page holográfica
- Estrutura em JSON para dados e relatórios
- API Flask para leitura de dados e resumo operacional
- Visual estático para GitHub Pages

---

## 🧪 Uso do Sistema

Ao iniciar, o sistema oferece um menu interativo com opções que permitem:

1. Ativar análise operacional
2. Simular previsões de missão
3. Executar camada quântica
4. Visualizar detalhes do projeto
5. Gerar gráfico de análise
6. Exportar landing page
7. Salvar estrutura de dados
8. Encerrar operação

## 📌 Observação Técnica

Este projeto tem caráter conceitual, acadêmico e de pesquisa aplicada. Não substitui normas regulamentares, engenharia certificada ou documentação oficial de aeronaves.
