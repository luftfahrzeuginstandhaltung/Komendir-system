# LexKomendirAircraft — Kit de apresentação

A identidade foi refinada para uma apresentação premium, institucional e orientada à aviação. O projeto permanece conceitual: não representa vínculo oficial com forças armadas, fabricantes ou autoridades e não controla aeronaves.

## Páginas

- `index.html` — página pública premium
- `investidor.html` — visão institucional para cliente, parceiro ou investidor
- `index_holograma.html` — experiência holográfica/cockpit

## Posicionamento

LexKomendirAircraft traduz pesquisa aplicada, formação técnica e organização de dados em uma linguagem visual de alta confiança. A estética combina preto técnico, azul ciano, dourado discreto, tipografia geométrica e sinais de telemetria.

## Publicação

Para GitHub Pages, mantenha o branch `main` e a pasta raiz `/`. A página inicial será `index.html`. Para a aplicação Flask, use um serviço compatível com Python e execute `python app.py`.

## Uso responsável

Os dados e métricas exibidos são demonstrativos. Não devem ser interpretados como telemetria real, certificação, instrução de manutenção ou autorização operacional.
